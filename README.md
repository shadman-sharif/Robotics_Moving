# Robotics – Robot Movement (Chapter 7)

A clean, simple, multi-language website based on the Bangla robotics book **সুখীর উল্লাসে রোবটিক্স** (Chapter 7: Robot Movement / রোবটের নড়াচড়া).

## Features

- **Projects 12–18** with the original circuit diagrams and project photos
- **Dark / Light theme** toggle (matches the provided switch style)
- **Language switcher**: English · বাংলা · 日本語 (full page translation)
- Simple robotic floating background animation
- Clean, organized, easy-to-read layout with slightly bold + italic text style
- Credits at the bottom

## How to open

1. Open the `Robotics` folder
2. Double-click `index.html`  
   (or serve the folder with any static server)
