# Project 12 — Servo Motor and Laser

## Purpose

Control a servo motor with an Arduino and use the servo movement for a simple scanning-style laser project.

## Main Components

- Arduino Uno
- SG90 or similar servo motor
- Jumper wires
- Laser module
- USB cable / suitable power source

## Basic Wiring

- Servo VCC → Arduino 5V
- Servo GND → Arduino GND
- Servo signal → Arduino digital pin 9

## Code

The Arduino source code is kept separately in `code/servo_laser.ino`.

## Book Reference

The included book pages show the servo wiring, Arduino setup, and sweep concept used for this project.
