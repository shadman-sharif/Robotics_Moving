# Project 15 — Biped Robot

## Purpose

Create a simple two-legged robot using four servo motors.

The book identifies the four servo positions as:

- Right foot
- Right thigh
- Left foot
- Left thigh

## Servo Connections

- Digital pin 3 → Right foot
- Digital pin 5 → Right thigh
- Digital pin 9 → Left foot
- Digital pin 6 → Left thigh

All servo grounds should share a common ground with the Arduino.

## Mechanical Construction

The supplied book pages show the servo pairs, cardboard-based mechanical structure, leg arrangement, and walking concept.

## Code

The Arduino source code is kept separately in `code/biped_robot.ino`.
