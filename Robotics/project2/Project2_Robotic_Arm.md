# প্রজেক্ট ২ (মূল বইয়ের প্রজেক্ট ১৩): রোবটিক আর্ম তৈরি

সারভো মোটর দিয়ে রোবটিক আর্ম তৈরি করা যায়। দুইটি সারভো ব্যবহার করে একটি সিম্পল গ্র্যাবার (গ্রাস্পার) বানানো যায়।

## ধারণা

দুই দিকে মুখ করে থাকা সারভো দিয়ে বস্তু ধরা ও ছাড়া যায়। 

যখন বস্তু ধরতে চাইব তখন হাত দুটিকে নিজেদের কাছাকাছি এগিয়ে আনতে হবে। দুইটারই কোণের পরিমাণ সমান পরিবর্তন করি!

দুইটা সারভোর কোণের গড় সমান - (100+0)/2 = 50

অতএব 0 ডিগ্রি সারভোকে আরও 50 ডিগ্রি বাড়িয়ে নিয়ে আসব 50 ডিগ্রি কোণে। অপরদিকে 100 ডিগ্রি সারভোকে আরও 50 ডিগ্রি কমিয়ে নিয়ে আসব 50 ডিগ্রি কোণে!

এবারে দুইটাই কাছাকাছি চলে আসবে, ফলে অবজেক্ট গ্র্যাব করতে পারবে!!

## সার্কিট ডায়াগ্রাম (চিত্র ৮৫)

### বামপাশে বসানো সারভোর পিন কানেকশন
| আরডুইনোর 5V          | সারভোর VCC |
| আরডুইনোর GND         | সারভোর GND |
| আরডুইনোর ডিজিটাল 10  | সারভোর কন্ট্রোল পিন |

### ডানপাশে বসানো সারভোর পিন কানেকশন
| আরডুইনোর 5V          | সারভোর VCC |
| আরডুইনোর GND         | সারভোর GND |
| আরডুইনোর ডিজিটাল 9   | সারভোর কন্ট্রোল পিন |

মনে রেখো তুমি চাইলে অন্য কিছু পিনে সারভোর কন্ট্রোল পিন যুক্ত করতে পারবে। কিন্তু অবশ্যই সেটা যেন PWM পিন হয়, অন্য পিনে সারভো কিন্তু কাজ করবে না!!!!

## কোড

```cpp
#include <Servo.h>
Servo servo1; //servo pins
Servo servo2;
void setup() {
  servo1.attach(10);
  servo2.attach(9);
}
void loop() {
  servo1.write(0);
  servo2.write(100);
  delay(2000);
  servo1.write(50);
  servo2.write(50);
  delay(2000);
}
```

আশা করি তুমি কোড দেখেই বুঝতে পারছ আমরা কী করেছি!
এবারে তুমি নিজে এ রকমভাবে রোবটিক আর্ম বানিয়ে আশপাশে কিউব বা অবজেক্ট তুলতে পারো কি না, দেখো।

এটা খুব সিম্পল একটা 2 DOF রোবটিক আর্ম। বেশি ভারী বস্তু ঠিকমতো তোলা যায় না। সেটার জন্য প্রয়োজন আরও শক্তিশালী রোবটিক আর্ম, যেখানে ভারী টর্কের সারভো ব্যবহার করা হবে। বাজারে সরাসরি রোবটিক আর্মও পাওয়া যায়!
