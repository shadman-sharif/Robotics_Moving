# Robotics Projects from "সৃষ্টির উল্লাসে রোবটিক্স" Book

This repository contains extracted text and code from the book chapter on Robot Movement (রোবটের নড়াচড়া).

**Project numbering:** Original Project 12 is treated as Project 1, and continues sequentially for 7 projects.

## Structure

```
robotics-projects/
├── README.md
├── master/
│   └── Master_All_Projects.md      # Combined master file
├── project1/ ... project7/         # Individual project markdown files
└── codes/                          # Separate Arduino .ino code files
```

## Projects Overview

1. **Servo Cat Laser Light Play** - Control SG90 servo for laser pointer play with cats.
2. **Robotic Arm** - Simple 2-servo gripper arm.
3. **Serial Servo Control** - Control servo angle via Serial Monitor.
4. **Bipedal Robot** - 4-servo walking robot.
5. **DC Motor Speed Test** - Experiment with different voltages.
6. **H-Bridge Direction Control** - Theory and logic for motor direction.
7. **L298N Motor Driver** - Full dual motor control with speed and direction.

## How to use

- Open individual project Markdown files for full instructions (in Bengali).
- Upload corresponding .ino files from `codes/` to Arduino IDE.
- Follow circuit diagrams described in the texts.
