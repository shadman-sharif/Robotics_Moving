# প্রজেক্ট ৬ — L298N দিয়ে দুই মোটর

মূল বইয়ের প্রজেক্ট ১৭। বইয়ের পাতা প্রায় ১৬০–১৬৬।

## কেন লাগে

মোটর দিয়ে রোবট হাঁটালে দুটো জিনিস নিয়ন্ত্রণ করতে হয়।

ক. PWM — গতি। আগেও দেখেছি। এনাবল পিনে PWM দিলে গতি বদলায়।

খ. H-bridge — ঘূর্ণনের দিক।

মোটর কোন দিকে ঘুরবে, সেটা নির্ভর করে ধনাত্মক-ঋণাত্মক প্রান্ত কীভাবে যুক্ত আছে তার ওপর। ইনপুট ভোল্টেজের পোলারিটি পাল্টালে ঘোরার দিক বদলায়। এই উল্টানোর কাজ H-bridge করে।

## H-bridge কী

চারটি সুইচ, মাঝখানে একটা মোটর। পুরো জিনিস দেখতে ইংরেজি H।

একপাশের দুই সুইচ ক্লোজ, বাকি দুই ওপেন — তড়িৎ এক দিকে, মোটর সেই দিকে ঘোরে।

অন্য জোড়া সুইচ ক্লোজ করলে তড়িৎ উল্টো দিকে, মোটরও উল্টো দিকে।

## লজিক টেবিল

IN1, IN2, IN3, IN4 ইনপুট।

| ইনপুট ১ | ইনপুট ২ | ফল |
|---|---|---|
| LOW | LOW | মোটর ঘুরবে না |
| HIGH | LOW | সামনের দিকে |
| LOW | HIGH | পেছনের দিকে |
| HIGH | HIGH | বন্ধ / ব্রেক |

এই লজিকে দুই মোটরকে কোন দিকে ঘুরবে তা নিয়ন্ত্রণ করা যায়।

গতির জন্য 4টি ইনপুটের বামে-ডানে দুই এনাবল পিন: ENA আর ENB। এখানে PWM। 0 মানে থেমে, 255 মানে পুরো গতি।

5V জাম্পার লাগানো থাকলে এনাবল সবসময় চালু, গতি কমানো-বাড়ানো যায় না। গতি চাইলে জাম্পার খুলে ENA/ENB Arduino-র PWM পিনে দাও।

## যা লাগবে

- L298N মোটর ড্রাইভার
- Arduino Uno
- জাম্পার তার
- 2টা গিয়ার ডিসি মোটর
- ব্যাটারি বা 12V অ্যাডাপ্টার
- স্ক্রু ড্রাইভার

ডায়াগ্রামে ব্যাটারি 3.7V 2000mAh, লেবেল E585460-4121 / E4104-L58-1। বইয়ের লেখায় 12V অ্যাডাপ্টারও আছে। মোটরের রেট দেখে সাপ্লাই দাও।

## সার্কিট

![L298N সার্কিট](../images/p17-circuit.png)

| L298N | Arduino / পাওয়ার |
|---|---|
| IN1 | ডিজিটাল 8 |
| IN2 | ডিজিটাল 7 |
| IN3 | ডিজিটাল 5 |
| IN4 | ডিজিটাল 4 |
| ENA | ডিজিটাল 9 (PWM) |
| ENB | ডিজিটাল 3 (PWM) |
| OUT1, OUT2 | প্রথম মোটরের দুই তার |
| OUT3, OUT4 | দ্বিতীয় মোটরের দুই তার |
| 12V / VS | ব্যাটারির ধনাত্মক |
| GND | ব্যাটারির ঋণাত্মক, আর Arduino GND কমন |
| 5V | Arduino 5V (লজিক) |

মোটরের পাওয়ার ব্যাটারি থেকে। Uno-র 5V দিয়ে মোটর চালাবে না। GND না মেলালে ড্রাইভার সিগন্যাল বোঝে না।

## কোড

ফাইল: `codes/project6_L298N.ino`

```cpp
int enA = 9, in1 = 8, in2 = 7;
int enB = 3, in3 = 5, in4 = 4;

void setup() {
  pinMode(enA, OUTPUT);
  pinMode(enB, OUTPUT);
  pinMode(in1, OUTPUT);
  pinMode(in2, OUTPUT);
  pinMode(in3, OUTPUT);
  pinMode(in4, OUTPUT);
  digitalWrite(in1, LOW);
  digitalWrite(in2, LOW);
  digitalWrite(in3, LOW);
  digitalWrite(in4, LOW);
}

void loop() {
  analogWrite(enA, 200);
  analogWrite(enB, 200);
  digitalWrite(in1, HIGH);
  digitalWrite(in2, LOW);
  digitalWrite(in3, HIGH);
  digitalWrite(in4, LOW);
  delay(2000);
  digitalWrite(in1, LOW);
  digitalWrite(in2, HIGH);
  digitalWrite(in3, LOW);
  digitalWrite(in4, HIGH);
  delay(2000);
  digitalWrite(in1, LOW);
  digitalWrite(in2, LOW);
  digitalWrite(in3, LOW);
  digitalWrite(in4, LOW);
  delay(1000);
}
```

## কোড A থেকে Z

বই বলে কোড বড় দেখে ভয় পেয়ো না।

1. প্রথমে ভ্যারিয়েবলে জানিয়ে দেওয়া কোন পিন কোন মোটরের। মোটর A: ENA, IN1, IN2। মোটর B: ENB, IN3, IN4।
2. `setup`-এ সব পিন OUTPUT। শুরুতে সব IN LOW, মোটর বন্ধ।
3. `analogWrite(enA, 255)` পুরো গতি। 200 একটু কম, নিরাপদ।
4. IN1 HIGH, IN2 LOW — মোটর A সামনে। IN3 HIGH, IN4 LOW — মোটর B সামনে। 2 সেকেন্ড।
5. IN উল্টো করলে দিক বদলায়। আরও 2 সেকেন্ড।
6. সব LOW — থেমে।

এক মোটর উল্টো ঘুরলে তার OUT-এর দুই তার উল্টে লাগাও।

গতি বাড়ানো-কমানো, বইয়ের speedControl:

```cpp
for (int i = 0; i < 256; i++) {
  analogWrite(enA, i);
  analogWrite(enB, i);
  delay(20);
}
for (int i = 255; i >= 0; i--) {
  analogWrite(enA, i);
  analogWrite(enB, i);
  delay(20);
}
```

প্রথম লুপ 0 থেকে 255, গতি বাড়ে। দ্বিতীয় লুপ 255 থেকে 0, গতি কমে।

## ছবির আগের লেখা (বই)

মোটর দিয়ে রোবট হাঁটালে দুটো জিনিস নিয়ন্ত্রণ: PWM দিয়ে গতি, H-bridge দিয়ে দিক।

আগে জেনেছি দিক নির্ভর করে ব্যাটারির ধনাত্মক-ঋণাত্মক কীভাবে যুক্ত। পোলারিটি পাল্টালে দিক বদলায়। এই কাজ H-bridge।

H-bridge-এ চার সুইচ, মাঝে মোটর। দেখতে H। এক জোড়া সুইচ ক্লোজ করলে তড়িৎ এক দিকে। অন্য জোড়া ক্লোজ করলে উল্টো দিকে, মোটরও উল্টো।

IN1 IN2 IN3 IN4 ইনপুট। দুই ইনপুট LOW হলে ঘোরে না। প্রথম সচল দ্বিতীয় বন্ধ হলে সামনে। প্রথম বন্ধ দ্বিতীয় সচল হলে পেছনে। এই লজিকে দুই মোটরের দিক।

গতির জন্য ENA আর ENB। 5V জাম্পার খুললেই গতি নিয়ন্ত্রণ, নাহলে শুধু পুরো গতি।

উপকরণ: L298N, আরডুইনো, জাম্পার, গিয়ার ডিসি মোটর, 12V অ্যাডাপ্টার, স্ক্রু ড্রাইভার। ডায়াগ্রামে আলাদা 3.7V 2000mAh ব্যাটারিও আছে।

## ছবির পরের লেখা (বই)

সার্কিটের পরে পিন: IN1 ডিজিটাল 8, IN2 ডিজিটাল 7, IN3 ডিজিটাল 5, IN4 ডিজিটাল 4, ENA ডিজিটাল 9, ENB ডিজিটাল 3। OUT1 OUT2 প্রথম মোটর, OUT3 OUT4 দ্বিতীয়। VS আর GND অ্যাডাপ্টার বা ব্যাটারি। আরডুইনোর GND সেই GND-এর সঙ্গে।

কোডের আগে বই বলে বড় দেখে ভয় পেয়ো না। ভ্যারিয়েবলে মোটর A-এর ENA IN1 IN2, মোটর B-এর ENB IN3 IN4।

directionControl: analogWrite 255, সামনে, তারপর দিক বদল, তারপর বন্ধ। speedControl: 0 থেকে 255 বাড়ে, 255 থেকে 0 কমে।
