# প্রজেক্ট ২ — রোবটিক আর্ম (গ্র্যাবার)

মূল বইয়ের প্রজেক্ট ১৩।

## ধারণা

দুইটা সারভো মুখোমুখি বসালে ছোট গ্র্যাবার হয়।

- একটা 0°, অন্যটা 100° → হাত খোলা
- দুটোই 50° → হাত কাছাকাছি, বস্তু ধরে

গড় = (0 + 100) / 2 = 50

## যা লাগবে

- Arduino Uno
- 2টা SG90
- ব্রেডবোর্ড
- জাম্পার
- কার্ডবোর্ডের হাত (হট গ্লু দিয়ে)

## সার্কিট

![প্রজেক্ট ১৩ সার্কিট](../images/p13-circuit.png)

দুই সারভোর লাল একসাথে 5V, কালো একসাথে GND। সিগন্যাল:

| সারভো | Arduino পিন |
|---|---|
| বাম (servo1) | ডিজিটাল 10 |
| ডান (servo2) | ডিজিটাল 9 |

ডায়াগ্রামে কমলা তার পিন 9 ও 10-এ।

## বানানো ছবি

![গ্র্যাবারের ছবি](../images/p13-photo.jpg)

কার্ডবোর্ডের ফালি হট গ্লু দিয়ে সারভোর হর্নে লাগানো। দুই হাত কাছাকাছি এলে ছোট জিনিস ধরা যায়। ভারী জিনিসের জন্য বেশি টর্কের সারভো লাগে।

## কোড

ফাইল: `codes/project2_robotic_arm.ino`

```cpp
#include <Servo.h>
Servo servo1;
Servo servo2;

void setup() {
  servo1.attach(10);
  servo2.attach(9);
}

void loop() {
  servo1.write(0);
  servo2.write(100);
  delay(2000);
  servo1.write(50);
  servo2.write(50);
  delay(2000);
}
```

কোণ নিজের হাতের অবস্থান দেখে বদলাতে হবে। 0 আর 180 সব সারভোতে একদিকে নাও ঘুরতে পারে।
