# প্রজেক্ট ১ — সারভো দিয়ে বিড়ালের লেজার লাইট খেলা

মূল বইয়ের প্রজেক্ট ১২। অধ্যায়: রোবটের নড়াচড়া।

## কী শিখব

সারভো মোটর নির্দিষ্ট কোণে ঘোরানো যায়। SG90 সাধারণত 0 থেকে 180 ডিগ্রি ঘোরে। সিগন্যাল তার PWM পিনে লাগাতে হয়।

সারভোর ভেতরে একটা ছোট ডিসি মোটর, গিয়ারবক্স আর পটেনশিওমিটার থাকে। পটেনশিওমিটার বর্তমান অবস্থান ফিডব্যাক দেয়, তাই সারভো লক্ষ্য কোণে গিয়ে থামে।

তারের রং:

- বাদামি / কালো = GND
- লাল = 5V
- কমলা / হলুদ = সিগন্যাল (PWM)

## যা লাগবে

- Arduino Uno
- SG90 সারভো
- জাম্পার তার
- লেজার লাইট (ঐচ্ছিক, বিড়াল খেলার জন্য)

## সার্কিট

![প্রজেক্ট ১২ সার্কিট](../images/p12-circuit.png)

| Arduino | সারভো |
|---|---|
| 5V | লাল (VCC) |
| GND | কালো/বাদামি |
| ডিজিটাল 9 (PWM) | কমলা সিগন্যাল |

সবুজ তার ডায়াগ্রামে পিন 9, লাল 5V, কালো GND।

কিছু সারভো 250 mA-এর বেশি টানে। SG90 সাধারণত Uno-র 5V থেকে চলে। বেশি টর্কের সারভোতে আলাদা পাওয়ার দাও, GND কমন রাখো।

## কোড

ফাইল: `codes/project1_servo_sweep.ino`

```cpp
#include <Servo.h>
Servo servo;
int angle = 0;

void setup() {
  servo.attach(9);
}

void loop() {
  for (angle = 0; angle < 180; angle++) {
    servo.write(angle);
    delay(15);
  }
  for (angle = 180; angle > 0; angle--) {
    servo.write(angle);
    delay(15);
  }
}
```

`Servo` লাইব্রেরি IDE-তে আগে থেকেই থাকে। `attach(9)` পিন 9-কে সিগন্যাল করে। `write(angle)` সেই ডিগ্রিতে পাঠায়। `delay(15)` ঘোরা মসৃণ রাখে।

সিগন্যাল পিন অবশ্যই PWM হতে হবে: 3, 5, 6, 9, 10, 11।

## লেজার খেলা

সারভোর হর্নে একটা খেলনা লেজার লাগিয়ে দাও। সারভো ঘুরলে দেয়ালে আলো ছুটবে। বিড়াল সেই আলোর পেছনে দৌড়ায়।

অতিরিক্ত: পটেনশিওমিটার দিয়ে কোণ নিয়ন্ত্রণ করতে পারো (IDE-র Servo → Knob উদাহরণ)।
