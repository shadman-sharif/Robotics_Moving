## ১. ভূমিকা

এর আগের অধ্যায় পর্যন্ত আমাদের রোবটের জন্য আমরা বিভিন্ন **ইনপুট-আউটপুট** নিয়ে কাজ করলেও রোবটকে কোনো রকম **নড়াচড়া** করাইনি!

রোবটকে নড়াচড়া করানোর জন্য ব্যবহার করা যায় **মোটর**।

অন্য মোটরগুলোর চেয়ে **সারভো মোটর** সহজে নিয়ন্ত্রণ করা যায়। আবার সারভো মোটরকে নির্দিষ্ট পজিশনে অবস্থান পরিবর্তন করা যায়। তুমি যদি বলে দাও — “এত ডিগ্রি কোণে অমুক পজিশনে চলে যাও” — সারভো সেই কাজটা করে দিতে পারবে।

সারভো মোটর দিয়ে তাই রোবটের **হাত-পা** দুটিই তৈরি করা যায়!  
তুমি যদি রোবটিক আর্ম বানাতে চাও, এই কাজ সহজেই করতে পারবে সারভো দিয়ে। আবার এমন সারভো আছে যেটা দিয়ে রোবটের চাকার সঙ্গে লাগিয়ে রোবটকে এক জায়গা থেকে আরেক জায়গায় ঘোরানো যায় (এগুলোকে **Continuous Rotation Servo** বলে)। হিউমানয়েড রোবটেও হাত-পা তৈরিতে বেশ কিছু সারভো মোটর ব্যবহার করা হয়।

## ২. সারভো মোটর

### সারভো আসলে কী?

সারভো একটা বিশেষ মোটর যেখানে এই মুহূর্তে কোন পজিশনে মোটর আছে, সেটার **ফিডব্যাক** নেওয়া হয়। তারপর সেই ফিডব্যাক থেকে সিদ্ধান্ত নেওয়া হয় মোটর কোন দিকে কত স্পিডে ঘুরবে।

#### সারভোর ভেতরে কী থাকে? (চিত্র ৮২)

একটা সারভো মোটরের ভেতরে মূলত একটা **ডিসি মোটর** থাকে। সেই মোটরের আউটপুটের সঙ্গে যুক্ত থাকে একটা **পটেনশিওমিটার**। পটেনশিওমিটার দিয়ে অবস্থান বা পজিশন নির্ধারণ করা যায়। পটেনশিওমিটার এই মুহূর্তে তার অবস্থান ফিডব্যাক দেয় সারভোর কন্ট্রোল ইউনিটের কাছে। কন্ট্রোল ইউনিট আগে থেকেই জানে আমরা ঠিক কোন পজিশনে যেতে চাচ্ছি। তাই পটেনশিওমিটারের ফিডব্যাক থেকে সে হিসাব করে আর কতটুকু যাওয়া বাকি। এরপর সে আবার ডিসি মোটরকে আরও ঘোরার নির্দেশ দেয়। এভাবে লক্ষ্য অনুযায়ী পজিশনে না পৌঁছানো পর্যন্ত কাজ চলতে থাকে।

### সারভোকে কীভাবে জানাব কতটুকু ঘুরতে চাই?

প্রতিটি সারভো মোটরের একটা নির্দিষ্ট কোণ পরিমাণ ঘোরার সক্ষমতা থাকে। যেমন **SG90** সারভো মোটর (বেশ জনপ্রিয়) **০–১৮০ ডিগ্রি** ঘুরতে পারে।

সারভো মোটর যে ঘুরবে এটাও কিন্তু **অ্যানালগ আউটপুট**। অ্যানালগ আউটপুট শুধু **PWM পিন** দিয়ে দেওয়া যায়। আমরা যখন আরডুইনো থেকে সিগন্যাল পাঠাব “অমুক ডিগ্রিতে ঘুরে যাও”, তখন আরডুইনো হিসাব করে নেবে PWM অনুযায়ী ডিউটি সাইকেল কত হলে এই ডিগ্রিতে ঘুরতে পারবে। তারপর সেই অনুযায়ী PWM সিগন্যাল পাঠায়।

#### সারভো মোটরের তার (চিত্র ৮৩)

- **বাদামি / কালো** → GND  
- **লাল** → VCC বা ৫V  
- **কমলা / হলুদ** → Control (PWM) পিন

## প্রজেক্ট ১  
### সারভো মোটর দিয়ে বিড়ালের লেজার লাইট খেলা  
*(মূল বই: প্রজেক্ট ১২)*

**যা লাগবে:**  
আরডুইনো, জাম্পার তার, SG90 সারভো মোটর, লেজার লাইট (খেলনা)।

### যেভাবে করব

**১. সার্কিট সেটআপ**

| আরডুইনো          | সারভো মোটর     |
|------------------|----------------|
| 5V               | VCC (লাল)      |
| GND              | GND (বাদামি)   |
| ডিজিটাল পিন ৯    | Control (কমলা) |

> **বিশেষ দ্রষ্টব্য:** কিছু সারভো ২৫০ mA-এর বেশি তড়িৎ নেয়। সেক্ষেত্রে আলাদা পাওয়ার সাপ্লাই দাও। SG90-এ সাধারণত সমস্যা হয় না।

**২. কোড লিখে আপলোড করো**

```cpp
#include <Servo.h>

Servo servo;
int angle = 0; // সারভো ঘোরার কোণ ডিগ্রি এককে

void setup() {
  servo.attach(9);   // ডিজিটাল পিন ৯
}

void loop() {
  // ০ থেকে ১৮০ ডিগ্রি কোণে যাবে
  for(angle = 0; angle < 180; angle++) {
    servo.write(angle);
    delay(15);
  }
  // আবার ১৮০ থেকে ০ ডিগ্রিতে ফিরবে
  for(angle = 180; angle > 0; angle--) {
    servo.write(angle);
    delay(15);
  }
}
```

### কোড ব্যাখ্যা

- `Servo` লাইব্রেরি আরডুইনো IDE-তে আগে থেকেই থাকে।
- `servo.attach(9)` → পিন ৯-এ কন্ট্রোল তার লাগানো।
- `for` লুপ দিয়ে ১ ডিগ্রি করে কোণ বাড়ানো/কমানো হচ্ছে।
- `delay(15)` → মসৃণ ঘূর্ণনের জন্য ছোট বিরতি।

**মজার কাজ:** সারভোর সাথে একটা লেজার লাইট জুড়ে দাও। সারভো ঘোরার সাথে সাথে দেয়ালে লেজারের আলো ছুটবে — বিড়াল খেলতে থাকবে!

**অতিরিক্ত চ্যালেঞ্জ:** পটেনশিওমিটার দিয়ে সারভোর কোণ নিয়ন্ত্রণ করো (Examples → Servo → Sweep ও Knob দেখো)।

> **মনে রেখো:** সারভোর কন্ট্রোল পিন অবশ্যই **PWM পিন** হতে হবে (৩, ৫, ৬, ৯, ১০, ১১)।

## প্রজেক্ট ২  
### রোবটিক আর্ম (গ্র্যাবার) তৈরি  
*(মূল বই: প্রজেক্ট ১৩)*

দুইটি সারভো দিয়ে একটা সাধারণ গ্র্যাবার (বস্তু ধরার হাত) বানানো যায়।

### ধারণা

- একটা সারভো ০° এ রাখো, অন্যটা ১০০° এ রাখো → হাত খোলা থাকে।
- দুটোকেই ৫০° এ নিয়ে আসো → হাত বন্ধ হয়ে বস্তু ধরে।

গড় কোণ = (০ + ১০০) / ২ = ৫০

### সার্কিট

**বাম সারভো (servo1):**  
আরডুইনো 5V → VCC, GND → GND, ডিজিটাল ১০ → Control

**ডান সারভো (servo2):**  
আরডুইনো 5V → VCC, GND → GND, ডিজিটাল ৯ → Control

### কোড

```cpp
#include <Servo.h>

Servo servo1;
Servo servo2;

void setup() {
  servo1.attach(10);
  servo2.attach(9);
}

void loop() {
  // হাত খোলা
  servo1.write(0);
  servo2.write(100);
  delay(2000);

  // হাত বন্ধ (গ্র্যাব)
  servo1.write(50);
  servo2.write(50);
  delay(2000);
}
```

এভাবে তুমি আশপাশের ছোট কিউব বা অবজেক্ট তুলতে পারবে। ভারী বস্তুর জন্য শক্তিশালী টর্কের সারভো লাগবে।

## প্রজেক্ট ৩  
### সিরিয়াল মনিটর দিয়ে সারভো নিয়ন্ত্রণ  
*(মূল বই: প্রজেক্ট ১৪)*

কম্পিউটারের সিরিয়াল মনিটর থেকে কোণ লিখে সারভোকে নির্দিষ্ট পজিশনে পাঠাবে।

### সার্কিট
প্রজেক্ট ১-এর মতোই (পিন ৯)।

### কোড (সহজ সংস্করণ)

```cpp
#include <Servo.h>

Servo myservo;

void setup() {
  Serial.begin(9600);
  myservo.attach(9);
  Serial.println("Servo ready. Enter angle (0-180):");
}

void loop() {
  if (Serial.available() > 0) {
    int angle = Serial.parseInt();
    if (angle >= 0 && angle <= 180) {
      myservo.write(angle);
      Serial.print("Moved to: ");
      Serial.println(angle);
    }
  }
}
```

সিরিয়াল মনিটরে ০ থেকে ১৮০-এর মধ্যে কোনো সংখ্যা লিখে Enter চাপলে সারভো সেই কোণে চলে যাবে।

## প্রজেক্ট ৪  
### বাইপেডাল (দুই পা বিশিষ্ট) রোবট

৪টি সারভো দিয়ে দুই পা তৈরি করে হাঁটার মতো নড়াচড়া করানো যায়।

### ধারণা
- প্রতি পায়ের জন্য দুটি সারভো: একটি **উরু**, একটি **পায়ের পাতা**।
- দুই জোড়া সারভোকে ৯০° কোণে মুখোমুখি জোড়া দাও।
- ক্রমান্বয়ে কোণ পরিবর্তন করে হাঁটার গেইট তৈরি করো।

### উপকরণ
৪টি SG90 সারভো, আরডুইনো, জাম্পার, কার্ডবোর্ড/ফ্রেম।

রেফারেন্স: [Instructables Simple Bipedal Robot](https://www.instructables.com/Make-A-Simple-Bipedal-Humanoid-Robot/)

### নমুনা কোড কাঠামো

```cpp
#include <Servo.h>

Servo leftThigh, leftFoot, rightThigh, rightFoot;

void setup() {
  leftThigh.attach(3);
  leftFoot.attach(5);
  rightThigh.attach(6);
  rightFoot.attach(9);
}

void loop() {
  // সরল হাঁটার সিকোয়েন্স (নিজের মতো করে টিউন করো)
  leftThigh.write(70);
  rightThigh.write(110);
  delay(400);
  leftFoot.write(60);
  rightFoot.write(120);
  delay(400);
  // আরও স্টেপ যোগ করো...
}
```

ক্যালিব্রেশন খুব গুরুত্বপূর্ণ — প্রথমে সব সারভো ৯০°-এ রেখে ফ্রেম বানাও।

## প্রজেক্ট ৫  
### ডিসি মোটরের গতি পরীক্ষা

ডিসি মোটর কীভাবে কাজ করে এবং ভোল্টেজ অনুযায়ী গতি কেমন বদলায় — সেটা দেখার প্রজেক্ট।

### তত্ত্ব সংক্ষেপে
ডিসি মোটরে তড়িৎ প্রবাহিত হলে চৌম্বক ক্ষেত্র তৈরি হয়। এই ক্ষেত্র স্থায়ী চুম্বকের সঙ্গে ক্রিয়া করে ঘূর্ণন তৈরি করে। **যত বেশি ভোল্টেজ, তত বেশি RPM**।

### পরীক্ষা
বিভিন্ন ব্যাটারি (৩V, ৬V, ৯V, ১২V) লাগিয়ে মোটরের গতি (RPM) পরিমাপ করো। দেখবে ভোল্টেজ বাড়লে গতি বাড়ে।

> পরবর্তী প্রজেক্টে আমরা এই গতি ও দিক দুটোই নিয়ন্ত্রণ করব।

## প্রজেক্ট ৬  
### H-Bridge দিয়ে মোটরের দিক নিয়ন্ত্রণ

### H-Bridge কী?
চারটি সুইচ + মাঝে একটা মোটর → ইংরেজি **H** অক্ষরের মতো দেখায়।

মোটরের পোলারিটি উল্টে দিলে ঘূর্ণনের দিক উল্টে যায়। H-Bridge দিয়েই এই কাজটা করা হয়।

### লজিক টেবিল

| IN1  | IN2  | ফলাফল             |
|------|------|-------------------|
| LOW  | LOW  | মোটর বন্ধ         |
| HIGH | LOW  | সামনের দিকে ঘোরে  |
| LOW  | HIGH | পেছনের দিকে ঘোরে  |
| HIGH | HIGH | মোটর বন্ধ (ব্রেক) |

এই লজিকই L298N-এর ভিত্তি।

## প্রজেক্ট ৭  
### L298N মোটর ড্রাইভার দিয়ে দুই মোটর চালানো

এখন আমরা **গতি + দিক** দুটোই নিয়ন্ত্রণ করব।

### উপকরণ
- L298N মোটর ড্রাইভার মডিউল  
- আরডুইনো  
- ২টি গিয়ার ডিসি মোটর  
- ১২V অ্যাডাপ্টার  
- জাম্পার তার  

### কানেকশন টেবিল

| L298N পিন     | আরডুইনো / পাওয়ার          |
|---------------|----------------------------|
| IN1           | ডিজিটাল ৮                  |
| IN2           | ডিজিটাল ৭                  |
| IN3           | ডিজিটাল ৫                  |
| IN4           | ডিজিটাল ৪                  |
| ENA           | ডিজিটাল ৯ (PWM)            |
| ENB           | ডিজিটাল ৩ (PWM)            |
| OUT1 & OUT2   | মোটর A-এর দুই তার          |
| OUT3 & OUT4   | মোটর B-এর দুই তার          |
| VCC / VS      | ১২V অ্যাডাপ্টার (+)        |
| GND           | ১২V অ্যাডাপ্টার (−) + আরডুইনো GND |
| আরডুইনো Vin   | ১২V অ্যাডাপ্টার (+)        |

> **গুরুত্বপূর্ণ:** L298N-এর ৫V জাম্পার **খুলে** রাখো যদি বাইরের পাওয়ার দিয়ে মোটর চালাও। তাহলেই ENA/ENB দিয়ে গতি নিয়ন্ত্রণ করা যাবে।

### সম্পূর্ণ কোড

```cpp
// Motor A connections
int enA = 9;
int in1 = 8;
int in2 = 7;

// Motor B connections
int enB = 3;
int in3 = 5;
int in4 = 4;

void setup() {
  pinMode(enA, OUTPUT);
  pinMode(enB, OUTPUT);
  pinMode(in1, OUTPUT);
  pinMode(in2, OUTPUT);
  pinMode(in3, OUTPUT);
  pinMode(in4, OUTPUT);

  // শুরুতে মোটর বন্ধ
  digitalWrite(in1, LOW);
  digitalWrite(in2, LOW);
  digitalWrite(in3, LOW);
  digitalWrite(in4, LOW);
}

void loop() {
  directionControl();
  delay(1000);
  speedControl();
  delay(1000);
}

void directionControl() {
  // সর্বোচ্চ গতি
  analogWrite(enA, 255);
  analogWrite(enB, 255);

  // সামনের দিকে
  digitalWrite(in1, HIGH);
  digitalWrite(in2, LOW);
  digitalWrite(in3, HIGH);
  digitalWrite(in4, LOW);
  delay(2000);

  // পেছনের দিকে
  digitalWrite(in1, LOW);
  digitalWrite(in2, HIGH);
  digitalWrite(in3, LOW);
  digitalWrite(in4, HIGH);
  delay(2000);

  // বন্ধ
  digitalWrite(in1, LOW);
  digitalWrite(in2, LOW);
  digitalWrite(in3, LOW);
  digitalWrite(in4, LOW);
}

void speedControl() {
  // সামনের দিকে চালু
  digitalWrite(in1, LOW);
  digitalWrite(in2, HIGH);
  digitalWrite(in3, LOW);
  digitalWrite(in4, HIGH);

  // ০ থেকে ২৫৫ পর্যন্ত গতি বাড়াও
  for (int i = 0; i < 256; i++) {
    analogWrite(enA, i);
    analogWrite(enB, i);
    delay(20);
  }

  // ২৫৫ থেকে ০ পর্যন্ত গতি কমাও
  for (int i = 255; i >= 0; --i) {
    analogWrite(enA, i);
    analogWrite(enB, i);
    delay(20);
  }

  // বন্ধ
  digitalWrite(in1, LOW);
  digitalWrite(in2, LOW);
  digitalWrite(in3, LOW);
  digitalWrite(in4, LOW);
}
```

এই কোড দিয়ে মোটরগুলো আগে দিক বদলাবে, তারপর গতি বাড়িয়ে-কমিয়ে দেখাবে।
