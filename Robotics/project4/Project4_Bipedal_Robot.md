# প্রজেক্ট ৪: বাইপেডাল (দুই পা বিশিষ্ট) রোবট

সারভো মোটর দিয়ে আমরা চাইলে মোটরকে নির্দিষ্ট পজিশনে নিয়ে যেতে পারি। এখানে আমরা সারভোর এই ক্ষমতা কাজে লাগাব। আমরা 4টি মোটর এমনভাবে যুক্ত করব যেন বিভিন্ন কোণে পজিশন পাল্টে দুই পায়ে ভর দিয়ে হাঁটার মতো নড়াচড়া করতে পারে।

## ধারণা
১. প্রথমে আমরা মোটরগুলোকে জোড়ায় জোড়ায় একসঙ্গে যুক্ত করব। দুটি মোটর একসঙ্গে নেব ও তাদের পাখা 90 ডিগ্রি কোণে মুখোমুখি করে জোড়া দেব।

এভাবে আমরা দুই জোড়া মোটর তৈরি করে ফেলি। এগুলোই আমাদের রোবটের দুই পা হিসেবে ব্যবহার হবে।

প্রতিটি পায়ের ক্ষেত্রে আমরা চিন্তা করি দুটি মোটর আছে, একটি মোটর পায়ের উরু হিসেবে কাজ করবে ও আরেকটি পায়ের নিচের অংশ বা পায়ের পাতা হিসেবে কাজ করবে।

## উপকরণ
4টি সারভো মোটর, জাম্পার তার, আরডুইনো, কার্ডবোর্ড বা ফ্রেম।

রেফারেন্স: https://www.instructables.com/Make-A-Simple-Bipedal-Humanoid-Robot/

কোড উদাহরণ (সংশোধিত):

```cpp
#include <Servo.h>
Servo leftThigh, leftFoot, rightThigh, rightFoot;

void setup() {
  leftThigh.attach(3);
  leftFoot.attach(5);
  rightThigh.attach(6);
  rightFoot.attach(9);
}

void loop() {
  // simple walking sequence
  leftThigh.write(90);
  rightThigh.write(90);
  delay(500);
  leftFoot.write(60);
  rightFoot.write(120);
  delay(500);
  // more steps for walking gait...
}
```

বিস্তারিত কোড এবং ক্যালিব্রেশন বইয়ের পৃষ্ঠা অনুসারে অনুসরণ করুন।
