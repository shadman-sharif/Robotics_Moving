ছবি এই ফোল্ডারের `images/` এ। ZIP খুলে এই ফাইল মার্কডাউন প্রিভিউতে খুললে ছবি দেখা যাবে। চ্যাটে শুধু টেক্সট দেখালে ছবি আলাদা ফাইল হিসেবে আছে।

## ১. সারভো কী

আগের অধ্যায় পর্যন্ত ইনপুট-আউটপুট হয়েছে, রোবট নড়েনি। নড়াচড়ার জন্য মোটর।

সারভো অন্য মোটরের চেয়ে সহজে নিয়ন্ত্রণ হয়। নির্দিষ্ট কোণে পাঠানো যায়। বললে “৯০ ডিগ্রিতে যাও”, সেখানে গিয়ে থামে। তাই হাত-পা বানানো যায়।

রোবটিক আর্ম, চাকা (কন্টিনিউয়াস রোটেশন সারভো), হিউম্যানয়েডের জয়েন্ট — সব জায়গায় সারভো লাগে। কন্টিনিউয়াস সারভো থেমে থাকে না, চাকার মতো ঘুরতেই থাকে।

### ভেতরে কী

একটা ছোট ডিসি মোটর, গিয়ারবক্স, আর পটেনশিওমিটার।

পটেনশিওমিটার বলে এখন কোথায় আছে। কন্ট্রোল ইউনিট জানে লক্ষ্য কোথায়। ফিডব্যাক দেখে বাকি ঘূর্ণন হিসাব করে, মোটরকে আরও ঘোরাতে বলে। লক্ষ্যে না পৌঁছানো পর্যন্ত এটা চলে।

### কত ডিগ্রি

SG90 জনপ্রিয়। সাধারণত ০ থেকে ১৮০ ডিগ্রি। এটা অ্যানালগ আউটপুট, তাই সিগন্যাল শুধু PWM পিনে: ৩, ৫, ৬, ৯, ১০, ১১। অন্য পিনে সারভো কাজ করে না।

আরডুইনোকে ডিগ্রি বললে Servo লাইব্রেরি ডিউটি সাইকেল হিসাব করে পালস পাঠায়। নিজে PWM লিখতে হয় না।

### তার

- বাদামি বা কালো = GND
- লাল = VCC, ৫V
- কমলা বা হলুদ = সিগন্যাল

কিছু সারভো ২৫০ mA-এর বেশি টানে। সেগুলোকে Uno-র ৫V থেকে না দিয়ে আলাদা সাপ্লাই দাও। GND অবশ্যই কমন। SG90 সাধারণত বোর্ড থেকেই চলে।

## প্রজেক্ট ১ — সারভো দিয়ে বিড়ালের লেজার লাইট

মূল প্রজেক্ট ১২।

যা লাগবে: Arduino Uno, জাম্পার, SG90, খেলনা লেজার।

### সার্কিট

![প্রজেক্ট ১২ সার্কিট ডায়াগ্রাম](images/p12-circuit.png)

ডায়াগ্রামে সবুজ তার পিন ৯, লাল ৫V, কালো GND।

| Arduino | সারভো |
|---|---|
| 5V | লাল |
| GND | কালো / বাদামি |
| ডিজিটাল ৯ | কমলা সিগন্যাল |

### কোড

`codes/project1_servo_sweep.ino`

```cpp
#include <Servo.h>
Servo servo;
int angle = 0;

void setup() {
  servo.attach(9);
}

void loop() {
  for (angle = 0; angle < 180; angle++) {
    servo.write(angle);
    delay(15);
  }
  for (angle = 180; angle > 0; angle--) {
    servo.write(angle);
    delay(15);
  }
}
```

Servo লাইব্রেরি IDE-তে আগে থেকেই থাকে। `attach(9)` মানে সিগন্যাল পিন ৯। `write(angle)` সেই ডিগ্রিতে পাঠায়। `write(0)` মানে ০ ডিগ্রি, `write(50)` মানে ৫০ ডিগ্রি।

for লুপের তিন অংশ: শুরু (`angle = 0`), শর্ত (`angle < 180`), বাড়ানো (`angle++`)। ০ থেকে ১৭৯ পর্যন্ত ১৮০ বার চলে। `delay(15)` না দিলে সারভো ঝাঁকুনি খায়।

দ্বিতীয় লুপ ১৮০ থেকে ১ পর্যন্ত ফেরে। তাই সারভো সামনে-পেছনে ঝাড়ে।

হর্নে একটা পাখা বা কাগজ লাগিয়ে ঘোরা দেখো। লেজার জুড়লে দেয়ালে আলো ছোটে। বিড়াল সেই আলোর পেছনে দৌড়ায়।

অতিরিক্ত: IDE-র Examples → Servo → Sweep এই প্রজেক্টের মতো। Knob উদাহরণে পটেনশিওমিটার দিয়ে কোণ নিয়ন্ত্রণ।

## প্রজেক্ট ২ — রোবটিক আর্ম

মূল প্রজেক্ট ১৩।

দুই সারভো মুখোমুখি। একটা ০°, অন্যটা ১০০° রাখলে হাত খোলা। দুটোকে ৫০°-এ আনলে কাছাকাছি আসে, জিনিস ধরে।

গড় = (100 + 0) / 2 = 50। তাই ০-কে ৫০ বাড়াও, ১০০-কে ৫০ কমাও।

### সার্কিট

![প্রজেক্ট ১৩ সার্কিট](images/p13-circuit.png)

দুই সারভোর লাল একসাথে ৫V, কালো একসাথে GND। সিগন্যাল আলাদা PWM পিনে।

| সারভো | পিন |
|---|---|
| বাম servo1 | ডিজিটাল ১০ |
| ডান servo2 | ডিজিটাল ৯ |

### বানানো ছবি

![কার্ডবোর্ডের দুই হাত](images/p13-photo.jpg)

কার্ডবোর্ডের ফালি হট গ্লু দিয়ে হর্নে লাগানো। হাত খোলা অবস্থায় দূরে, বন্ধ করলে কাছাকাছি। ভারী জিনিস তোলে না। বেশি টর্কের সারভো লাগে। বাজারে ২ DOF আর্মও পাওয়া যায়, সেখানেও কোণ বদলে ধরা-ছাড়া হয়।

### কোড

`codes/project2_robotic_arm.ino`

```cpp
#include <Servo.h>
Servo servo1;
Servo servo2;

void setup() {
  servo1.attach(10);
  servo2.attach(9);
}

void loop() {
  servo1.write(0);
  servo2.write(100);
  delay(2000);
  servo1.write(50);
  servo2.write(50);
  delay(2000);
}
```

কোণ নিজের হাত দেখে বদলাও। সব সারভো ০ ডিগ্রিতে একদিকে ঘোরে না।

## প্রজেক্ট ৩ — সিরিয়াল মনিটর

মূল প্রজেক্ট ১৪।

সার্কিট প্রজেক্ট ১-এর মতো। সিগন্যাল পিন ৯।

![প্রজেক্ট ১৪ সার্কিট](images/p14-circuit.png)

মনিটরে ১০ থেকে ১৭০-এর মধ্যে সংখ্যা লিখে Enter দিলে সারভো সেখানে যায়। আগে ক্যালিব্রেশন: ০, ১৮০, ৯০ লিখে হর্ন সোজা করো।

`codes/project3_serial_servo.ino`

```cpp
#include <Servo.h>
Servo myservo;

void setup() {
  Serial.begin(9600);
  myservo.attach(9);
  Serial.println("Angle likho (0-180):");
}

void loop() {
  if (Serial.available() > 0) {
    int angle = Serial.parseInt();
    if (angle >= 0 && angle <= 180) {
      myservo.write(angle);
      Serial.print("Gelo: ");
      Serial.println(angle);
    }
  }
}
```

বোর্ড রেট ৯৬০০। বাক্সে “No line ending” বা Newline — Enter-এর পর সংখ্যা পড়া না গেলে লাইন এন্ডিং বদলাও।

## প্রজেক্ট ৪ — বাইপেডাল

মূল প্রজেক্ট ১৫।

চার সারভো। জোড়ায় জোড়ায়। একটা উরু, একটা পায়ের পাতা। দুই জোড়া মানে দুই পা। কোণ পাল্টালে এক পায়ে ভর দিয়ে অন্য পা সরানো যায়।

আগে সব সারভো ৯০° দিয়ে হর্ন লাগাও। নাহলে পা উল্টো দিকে যায়।

চার সারভো একসাথে Uno-র ৫V টানলে বোর্ড রিসেট হতে পারে। সারভোর VCC আলাদা ৫V থেকে দাও, GND কমন রাখো।

## প্রজেক্ট ৫ — ডিসি মোটর

মোটরের ভেতরে তড়িচ্ছুম্বক আর স্থায়ী চুম্বক। ব্রাশ কারেন্ট পৌঁছে দেয়।

![ডিসি মোটরের ভেতরে](images/fig94-dc-inside.jpeg)



মূল প্রজেক্ট ১৬। Arduino নেই।

বাড়ির লাইনের কারেন্ট AC, বারবার দিক বদলায়। ব্যাটারি DC।

![৯ ভোল্ট আর মোটর](images/p16-circuit.png)

## প্রজেক্ট ৬ — L298N

মূল প্রজেক্ট ১৭।

H-bridge-এ চার সুইচ, মাঝে মোটর। দেখতে H। পোলারিটি উল্টালে দিক বদলায়। L298N-এ দুই চ্যানেল, দুই মোটর।

| IN1 | IN2 | ফল |
|---|---|---|
| LOW | LOW | থেমে |
| HIGH | LOW | সামনে |
| LOW | HIGH | পেছনে |
| HIGH | HIGH | ব্রেক |

ENA আর ENB-তে PWM (০–২৫৫) দিলে গতি বদলায়। জাম্পার লাগানো থাকলে এনাবল সবসময় হাই, গতি বদলায় না। গতি চাইলে জাম্পার খুলে ENA/ENB Arduino-র PWM-এ দাও।

### সার্কিট

![L298N সার্কিট](images/p17-circuit.png)

ডায়াগ্রামে ব্যাটারি 3.7V 2000mAh, লেবেল E585460-4121 / E4104-L58-1। লাল প্লাস L298N-এর মোটর পাওয়ারে, কালো GND। সেই GND Arduino GND-এর সঙ্গে কমন।

| L298N | Arduino |
|---|---|
| ENA | ৯ |
| IN1 | ৮ |
| IN2 | ৭ |
| IN3 | ৫ |
| IN4 | ৪ |
| ENB | ৩ |
| OUT1 OUT2 | মোটর A |
| OUT3 OUT4 | মোটর B |

মোটরের পাওয়ার ব্যাটারি থেকে। Uno-র ৫V দিয়ে মোটর চালাবে না।

### কোড

`codes/project6_L298N.ino`

```cpp
int enA = 9, in1 = 8, in2 = 7;
int enB = 3, in3 = 5, in4 = 4;

void setup() {
  pinMode(enA, OUTPUT);
  pinMode(enB, OUTPUT);
  pinMode(in1, OUTPUT);
  pinMode(in2, OUTPUT);
  pinMode(in3, OUTPUT);
  pinMode(in4, OUTPUT);
}

void loop() {
  analogWrite(enA, 200);
  analogWrite(enB, 200);
  digitalWrite(in1, HIGH);
  digitalWrite(in2, LOW);
  digitalWrite(in3, HIGH);
  digitalWrite(in4, LOW);
  delay(2000);
  digitalWrite(in1, LOW);
  digitalWrite(in2, HIGH);
  digitalWrite(in3, LOW);
  digitalWrite(in4, HIGH);
  delay(2000);
  digitalWrite(in1, LOW);
  digitalWrite(in2, LOW);
  digitalWrite(in3, LOW);
  digitalWrite(in4, LOW);
  delay(1000);
}
```

এক মোটর উল্টো ঘুরলে OUT তার উল্টে দাও।

গতি বাড়ানোর লুপ:

```cpp
for (int i = 0; i < 256; i++) {
  analogWrite(enA, i);
  analogWrite(enB, i);
  delay(20);
}
```

```cpp
#include <Adafruit_MotorShield.h>
Adafruit_MotorShield AFMS = Adafruit_MotorShield();

  motor2->run(FORWARD);
  delay(2000);
```

## বইয়ের পাতার লেখা

নিচের অংশ বইয়ের পাতা থেকে। আগের সার্কিট, ছবি, কোড একই আছে।

### সপ্তম অধ্যায় — রোবটের নড়াচড়া

প্রজেক্ট ১২: সারভো মোটর দিয়ে বিড়ালের লেজার লাইট খেলা।

এর আগের অধ্যায় পর্যন্ত আমাদের রোবটের জন্য আমরা বিভিন্ন ইনপুট-আউটপুট নিয়ে কাজ করলেও রোবটকে কোনো রকম নড়াচড়া করাইনি। রোবটকে নড়াচড়া করানোর জন্য ব্যবহার করা যায় মোটর।

অন্য মোটরগুলোর চেয়ে সারভো মোটর সহজে নিয়ন্ত্রণ করা যায়। আবার সারভো মোটরকে নির্দিষ্ট পজিশনে অবস্থান পরিবর্তন করা যায়। তুমি যদি বলে দাও এত ডিগ্রি কোণে অমুক পজিশনে চলে যাও সারভো, তোমাকে সেই কাজটা করে দিতে পারবে। সারভো মোটর দিয়ে তাই রোবটের হাত-পা দুটিই তৈরি করা যায়। হেঁয়ালি না করি। তুমি ধরো রোবটিক আর্ম বানাতে চাও, এই কাজ সহজেই করতে পারবে সারভো দিয়ে। আবার ধরো এমন সারভো আছে যেটা দিয়ে রোবটের চাকার সঙ্গে লাগিয়ে রোবটকে এক জায়গা থেকে আরেক জায়গায় ঘোরানো যায়। অনবরত ঘুরতে থাকে বলে এ ধরনের সারভোকে কন্টিনিউয়াস রোটেশন সারভো বলে। আবার তুমি যদি হিউমানয়েড কোনো রোবট বানাতে চাও, সেখানেও দেখবে রোবটের হাত-পা তৈরিতে বেশ কিছু সারভো মোটর ব্যবহার করা হচ্ছে।

### সারভো আসলে কী?

সারভো একটা বিশেষ মোটর যেখানে এই মুহূর্তে কোন পজিশনে মোটর আছে, সেটার ফিডব্যাক নেওয়া হয়। তারপর সেই ফিডব্যাক থেকে সিদ্ধান্ত নেওয়া হয় মোটর কোন দিকে কত স্পিডে ঘুরবে।

চিত্র ৮২: সারভোর ভেতরে যা থাকে। একটা সারভো মোটরের ভেতরে মূলত একটা ডিসি মোটর থাকে। ডিসি মোটর কী জিনিস, আমরা কিছুক্ষণ পরেই জানব। আপাতত ধরে নিই সারভো মোটরের ভেতরে একটা সাধারণ মোটর থাকে। সেই মোটরের আউটপুটের সঙ্গে যুক্ত থাকে একটা পটেনশিওমিটার। আমরা জানি পটেনশিওমিটার দিয়ে অবস্থান বা পজিশন নির্ধারণ করা যায়। পটেনশিওমিটার এই মুহূর্তে তার অবস্থান ফিডব্যাক দেয় সারভোর কন্ট্রোল ইউনিটের কাছে। কন্ট্রোল ইউনিট আগে থেকেই জানে আমরা ঠিক কোন পজিশনে যেতে চাচ্ছি। তাই পটেনশিওমিটারের ফিডব্যাক থেকে সে হিসাব করে আর কতটুকু যাওয়া বাকি লক্ষ্য অনুযায়ী। এরপর সে আবার ডিসি মোটরকে আরও ঘোরার নির্দেশ দেয়। এভাবে লক্ষ্য অনুযায়ী পজিশনে না পৌঁছানো পর্যন্ত কাজ চলতে থাকে।

### সারভোকে কীভাবে জানাব কতটুকু ঘুরতে চাই?

প্রতিটি সারভো মোটরের একটা নির্দিষ্ট কোণ পরিমাণ ঘোরার সক্ষমতা থাকে। যেমন SG90 সারভো মোটর যেটা বেশ জনপ্রিয় একটা সারভো মোটর, 0-180 ডিগ্রি ঘুরতে পারে। সারভো মোটর যে ঘুরবে এটাও কিন্তু অ্যানালগ আউটপুট। এর আগে আমরা জেনেছি অ্যানালগ আউটপুট শুধু PWM পিন দিয়ে দেওয়া যায়। আমরা যখন আরডুইনো থেকে সিগন্যাল পাঠাব অমুক ডিগ্রিতে ঘুরে যাও, তখন আরডুইনো হিসাব করে নেবে PWM অনুযায়ী এখন ডিউটি সাইকেল কত হলে এই ডিগ্রিতে ঘুরতে পারবে সারভো। তারপর সেই অনুযায়ী PWM সিগন্যাল পাঠায়।

চিত্র ৮৩: সারভো মোটরের বিভিন্ন তার। এখানে আমরা দেখতে পাচ্ছি আমাদের সারভো মোটরের মোট তিনটি পিন। বামপাশের বাদামি তার হলো GND, মাঝের লাল তার VCC বা 5V এবং ডানপাশের কমলা তার কন্ট্রোল পিন (PWM আউটপুট এই পিনেই আরডুইনো দেবে)।

এবারে আমরা সারভো মোটর নিয়ে একটা প্রজেক্ট করে ফেলি।

যা লাগবে: আরডুইনো, জাম্পার তার, সারভো মোটর, লেজার লাইট।

যেভাবে করব: প্রথমে সার্কিট সেটআপ করি। চিত্র ৮৪: প্রজেক্ট ১২-এর সার্কিট ডায়াগ্রাম।

আরডুইনোর 5V — সারভো মোটরের VCC। আরডুইনোর GND — সারভো মোটরের GND। আরডুইনোর ডিজিটাল 9 — সারভো মোটরের কন্ট্রোল পিন।

বিশেষ দ্রষ্টব্য: কিছু কিছু সারভো মোটর 250 mA-এর চেয়ে আরও বেশি তড়িৎ প্রবাহ গ্রহণ করে। তাই সেগুলোকে আরডুইনো থেকে সরাসরি পাওয়ার সাপ্লাই না দিয়ে অন্য কোনো ব্যাটারি বা ভিন্ন পাওয়ার সাপ্লাই থেকে দেওয়া হয়। কিন্তু এই মুহূর্তে আমরা যেই সারভো মোটর ব্যবহার করছি, সেখানে এমন সমস্যা নেই।

এবারে নিচের কোড লিখে ফেলি। এখানে প্রথমেই আমরা Servo লাইব্রেরি ইনক্লুড করেছি। এটা আরডুইনো আইডিইতে আগে থেকেই ছিল, তাই নতুন করে ডাউনলোড করে লাইব্রেরি ম্যানেজারে ইনক্লুড করার ঝামেলা নেই।

সারভো লাইব্রেরি আমাদের কাজ অনেক সহজ করে দেয়। আমাদের আলাদা করে PWM-এ সারভোর ভ্যালু এই কোডে রূপান্তর করে নিতে হয় না, সারভো লাইব্রেরি নিজেই সেই কাজ করে নেয়।

এরপর আমরা servo নামে Servo লাইব্রেরির একটা অবজেক্ট তৈরি করে নিয়েছি। এই অবজেক্টের মাধ্যমে কোডে আমাদের সারভোকে সব সময় ব্যবহার করা হবে।

সেটআপ ফাংশনের ভেতরে আমরা লিখেছি servo.attach(9)। এর মানে হচ্ছে ডিজিটাল 9 পিনে আমাদের সারভোর কন্ট্রোল পিন যুক্ত আছে। সেটা আমাদের অবজেক্টের সঙ্গে অ্যাটাচ করে নিচ্ছি। এর ফলে যখনই servo নামের অবজেক্ট নিয়ে আমরা কাজ করতে যাব, আরডুইনো বুঝতে পারবে কাজটা আসলে করতে হবে ডিজিটাল 9 নম্বর পিনে।

লুপের ভেতরে আমরা সারভো মোটরকে 0 ডিগ্রি থেকে 180 ডিগ্রি পর্যন্ত ঘোরাব 1 ডিগ্রি করে পরিবর্তন করে। মানে প্রথমে সারভো 0 ডিগ্রিতে যাবে, এরপর 1 ডিগ্রিতে, তারপর 2 ডিগ্রিতে, 3 ডিগ্রিতে এভাবে করে 180 ডিগ্রি পর্যন্ত। যেকোনো একটা নির্দিষ্ট কোণে সারভোকে ঘোরানোর জন্য আমাদের লিখতে হবে servo.write(angle)। এখানে angle-এর মধ্যে বলে দিতে হবে কত ডিগ্রি।

যেমন যদি আমরা লিখি servo.write(0) তাহলে 0 ডিগ্রিতে অবস্থান করবে। যদি লিখি servo.write(50) তাহলে 50 ডিগ্রিতে ঘুরে যাবে।

কিন্তু তুমি একবার চিন্তা করো, 0 থেকে 180 ডিগ্রি পর্যন্ত ঘোরাতে তোমাকে 180 বার এই servo.write(angle) লাইনটা লিখতে হবে। তুমি কি 180 বার এই লাইন লিখবে? তাহলে তো অনেক বেশি সময় চলে যাবে। আচ্ছা আমরা যে লুপ ফাংশন ব্যবহার করছি, সেটার কাজ মনে আছে তো? লুপের ভেতরে যা কিছু লিখব, সেগুলো অনবরত চলতে থাকে।

এখন আমরা যদি একটা লুপ লিখি যেটা অসংখ্য বার না চলে যতবার আমরা চাইব ততবারই চলবে? যেমন এ ক্ষেত্রে 180 বার চলতে পারে এমন একটা লুপ যদি আমরা লিখি? ওহ আচ্ছা 180 বার হুবহু একই কাজ হলে কিন্তু মুশকিল। দেখা যাবে 180 বার একই ভ্যালু পাচ্ছি আমরা। আমাদের তো প্রতিবার 1 ডিগ্রি করে ভ্যালু পরিবর্তন করা দরকার।

এ কাজ কীভাবে করব? মানে 180 বার লুপ চালাব, কিন্তু প্রতিবার angle-এর ভ্যালু 1 করে পরিবর্তন হবে। এ কাজ খুব সহজে করা যায় for লুপ দিয়ে। এটা একটা মজার লুপ।

For লুপের তিনটা প্যারামিটার থাকে।

ক. initialization: কত ভ্যালু থেকে শুরু করব — যেমন আমরা শুরু করব এ ক্ষেত্রে 0 থেকে।

খ. condition: কত ভ্যালুতে গিয়ে থামব? যেমন আমাদের 180 এরপর থেমে যাওয়া দরকার।

গ. iteration: প্রতিবার ভ্যালু কতটুকু করে পরিবর্তন হবে? যেমন আমাদের প্রতিবার 1 করে ভ্যালু বাড়াতে হবে।

for(angle = 0; angle < 180; angle++) { servo.write(angle); delay(15); }

এখানে আমরা সেমিকোলন দিয়ে আলাদা আলাদা করে তিনটি জিনিসই for লুপে লিখে দিয়েছি। angle = 0 লিখে দিয়ে বুঝিয়েছি আমরা 0 ডিগ্রি থেকে শুরু করছি। তারপর বলেছি angle < 180 অর্থাৎ 180-এর আগে তথা 179 ডিগ্রিতে লুপটি থামবে (0 থেকে 179 পর্যন্ত মোট 180 বার লুপ রান হবে)। এরপর আবার লিখেছি angle++ যেখানে ++ মানে হচ্ছে 1 করে বাড়াও।

এবারে কী হচ্ছে বুঝতে পারছ? angle-এর মান শুরু হচ্ছে 180 থেকে। প্রতিবার কন্ডিশন যাচাই করব angle-এর মান 0-এর চেয়ে বেশি কি না। 0 না হওয়া পর্যন্ত প্রতিবার 1 ডিগ্রি করে কমে যাচ্ছে। অর্থাৎ 180 ডিগ্রি থেকে শুরু করে 1 ডিগ্রিতে সারভো এসে থামবে।

তুমি যদি কোড রান করো তাহলে এভাবে সারভোর ঘোরা দেখতে পারবে। সারভোর সঙ্গে অবশ্যই একটা পাখা যুক্ত করে নেবে, তাহলে বুঝতে সুবিধা হবে।

মনে রেখো তুমি চাইলে অন্য কিছু পিনে সারভোর কন্ট্রোল পিন যুক্ত করতে পারবে। কিন্তু অবশ্যই সেটা যেন PWM পিন হয়, অন্য পিনে সারভো কিন্তু কাজ করবে না।

এবারে আমরা একটা মজার কাজ করি। তোমরা অনেকে নিশ্চয়ই খেলনা লেজার লাইট দেখেছ? যেটা একবার বাটনে চাপ দিলে যতক্ষণ আবার চাপ না দাও একটা লেজার আলো বের হতেই থাকে। তোমার বাসায় কি কোনো বিড়াল আছে? বিড়ালরা কিন্তু লেজার আলো দেয়ালে দেখলে তার পেছনে ছুটে বেড়ায় ও মজা পায়, এটা নিয়ে খেলা করে। তুমি তোমার সারভোর সঙ্গে একটা এ রকম খেলনা লেজার জুড়ে দিতে পারো। তাহলে সারভো ঘোরার সঙ্গে সঙ্গে সামনে থাকা দেয়ালে লেজার ছুটতে থাকবে আর তোমার প্রিয় বিড়ালটা একটা খেলার সুযোগ পাবে।

সারভো দিয়ে আমরা আরও অনেক মজার কাজ করতে পারি। তুমি পটেনশিওমিটার দিয়ে এলইডির উজ্জ্বলতা পরিবর্তন করেছ আগে। একইভাবে সারভো কত ডিগ্রিতে ঘুরবে সেটা কি নিয়ন্ত্রণ করতে পারবে? চেষ্টা করে দেখো তো। Examples-এর মধ্যে সারভো লাইব্রেরির দুটি কোড পাবে। আমরা যেই প্রজেক্ট ওপরে করলাম এটা sweep নামে কোডে পাবে। আর তোমাকে পটেনশিওমিটার দিয়ে নিয়ন্ত্রণ করতে হবে।

### প্রজেক্ট ১৩: রোবটিক আর্ম তৈরি

দুই দিকে মুখ করে আছে অর্থাৎ বস্তু এখন ধরতে পারবে না। বা আগে যদি ধরা থাকে এখন তাহলে ছেড়ে দেবে।

আর যখন বস্তু ধরতে চাইব তখন তাহলে কী করব? তখন হাত দুটিকে নিজেদের কাছাকাছি এগিয়ে আনতে হবে। আমরা দুইটারই কোণের পরিমাণ সমান পরিবর্তন করি।

দুইটা সারভোর কোণের গড় সমান = (100+0)/2 = 50।

অতএব 0 ডিগ্রি সারভোকে আরও 50 ডিগ্রি বাড়িয়ে নিয়ে আসব 50 ডিগ্রি কোণে। অপরদিকে 100 ডিগ্রি সারভোকে আরও 50 ডিগ্রি কমিয়ে নিয়ে আসব 50 ডিগ্রি কোণে। এবারে দুইটাই কাছাকাছি চলে আসবে, ফলে অবজেক্ট গ্র্যাব করতে পারবে।

চিত্র ৮৫: প্রজেক্ট ১৩-এর সার্কিট ডায়াগ্রাম।

বামপাশে বসানো সারভোর পিন কানেকশন: আরডুইনোর 5V সারভোর VCC, আরডুইনোর GND সারভোর GND, আরডুইনোর ডিজিটাল 10 সারভোর কন্ট্রোল পিন।

ডানপাশে বসানো সারভোর পিন কানেকশন: আরডুইনোর 5V সারভোর VCC, আরডুইনোর GND সারভোর GND, আরডুইনোর ডিজিটাল 9 সারভোর কন্ট্রোল পিন।

মনে রেখো তুমি চাইলে অন্য কিছু পিনে সারভোর কন্ট্রোল পিন যুক্ত করতে পারবে। কিন্তু অবশ্যই সেটা যেন PWM পিন হয়, অন্য পিনে সারভো কিন্তু কাজ করবে না।

আশা করি তুমি কোড দেখেই বুঝতে পারছ আমরা কী করেছি। এবারে তুমি নিজে এ রকমভাবে রোবটিক আর্ম বানিয়ে আশপাশে কিউব বা অবজেক্ট তুলতে পারো কি না, দেখো।

চিত্র ৮৬: রোবটিক আর্ম তৈরি। আমাদের রোবটিক আর্ম দেখতে এ রকম হয়েছিল। তবে এটা দিয়ে বেশি ভারী বস্তু ঠিকমতো তোলা যায় না। সেটার জন্য প্রয়োজন আরও শক্তিশালী রোবটিক আর্ম, যেখানে ভারী টর্কের সারভো ব্যবহার করা হবে। যেমন বাজারে সরাসরি রোবটিক আর্মও পাওয়া যায়। তুমি চাইলে চিত্র ৮৭-এর মতো 2 DOF রোবটিক আর্ম কিনে নিতে পারো, যেটা একটা সারভো দিয়ে চলে এবং সে ক্ষেত্রেও সারভোর পজিশন পরিবর্তন করে তুমি অবজেক্ট গ্র্যাব করতে পারবে।

### প্রজেক্ট ১৪: সিরিয়াল দিয়ে সারভো

যা লাগবে: সারভো মোটর, জাম্পার তার।

যেভাবে করব: প্রথমে চিত্র ৮৮-এর মতো সার্কিট সেটআপ করে ফেলি। আরডুইনোর 5V সারভো মোটরের VCC, আরডুইনোর GND সারভো মোটরের GND, আরডুইনোর ডিজিটাল 9 সারভো মোটরের কন্ট্রোল পিন।

10-170 ডিগ্রির মধ্যে তুমি সিরিয়াল মনিটর থেকে একটি কোণের মান সাবমিট করতে পারবে। তখন সারভো নির্দিষ্ট দিকে ঘুরবে। সারভোকে 50 ডিগ্রি কোণে ঘুরতে বললে সে ক্যালিব্রেশন করে সেই পজিশনে যায়।

### বাইপেডাল

সারভো মোটর দিয়ে আমরা চাইলে মোটরকে নির্দিষ্ট পজিশনে নিয়ে যেতে পারি। এখানে আমরা সারভোর এই ক্ষমতা কাজে লাগাব। আমরা 4টি মোটর এমনভাবে যুক্ত করব যেন বিভিন্ন কোণে পজিশন পাল্টে দুই পায়ে ভর দিয়ে হাঁটার মতো নড়াচড়া করতে পারে।

প্রথমে আমরা মোটরগুলোকে জোড়ায় জোড়ায় একসঙ্গে যুক্ত করব। দুটি মোটর একসঙ্গে নেব ও তাদের পাখা 90 ডিগ্রি কোণে মুখোমুখি করে জোড়া দেব। এভাবে আমরা দুই জোড়া মোটর তৈরি করে ফেলি। এগুলোই আমাদের রোবটের দুই পা হিসেবে ব্যবহার হবে।

প্রতিটি পায়ের ক্ষেত্রে আমরা চিন্তা করি দুটি মোটর আছে, একটি মোটর পায়ের উরু হিসেবে কাজ করবে ও আরেকটি পায়ের নিচের অংশ বা পায়ের পাতা হিসেবে কাজ করবে।

### ডিসি মোটর

এমন তড়িৎ প্রবাহ, যার বারবার দিক পরিবর্তন হয়, সেটা AC। আমাদের বাসার কারেন্টের লাইনে AC তড়িৎ প্রবাহ হয়। পাশাপাশি একটা ব্যাটারি থাকে, যা থেকে DC তড়িৎ প্রবাহিত হয়।

ডিসি মোটরে তড়িৎ প্রবাহিত হলে একটি চৌম্বক ক্ষেত্র তৈরি হয়। এই চৌম্বক ক্ষেত্রের প্রভাবে তড়িচ্ছুম্বকটি স্থায়ী চুম্বকের দিকে আকৃষ্ট হয় ও এর চারপাশে একটি ঘূর্ণন করতে থাকে। এখানে তড়িচ্ছুম্বকে যত বেশি তড়িৎ প্রবাহিত হবে, তত বেশি আকর্ষণ কাজ করবে, অর্থাৎ তত বেশি গতিতে এটি ঘুরতে থাকবে। আবার কম তড়িৎ প্রবাহিত হলে একইভাবে ঘূর্ণনের গতি কমে যাবে।

আমরা এবার ডিসি মোটরের ঘূর্ণন ও এর গতির পরিবর্তন বোঝার জন্য একটি প্রজেক্ট করব। যা করতে যাচ্ছি: ডিসি মোটরের সঙ্গে আমরা ভিন্ন ভিন্ন ভোল্টেজের ব্যাটারি যুক্ত করব। করে দেখব কোন ক্ষেত্রে মোটর কেমন গতিতে ঘোরে। RPM কম-বেশি হওয়ার কারণ হচ্ছে দুই ক্ষেত্রে পাওয়ার সরবরাহ আলাদা। যত বেশি সরবরাহ করবে, তত বেশি স্পিড।

### H-bridge

মোটরের মাধ্যমে যখন আমরা কোনো রোবটকে হাঁটাই তখন দুটি জিনিস আমাদের নিয়ন্ত্রণ করতে হয়।

ক. PWM: PWM নিয়ন্ত্রণ করা আমরা আগেও দেখেছি। এটার মাধ্যমেই আমরা মোটরের গতি নিয়ন্ত্রণ করব।

খ. H-bridge: এটার মাধ্যমে মোটরের ঘূর্ণনের দিক নিয়ন্ত্রণ করা হবে।

আমরা এর আগে জেনেছি মোটর কোন দিকে ঘুরবে, সেটা আসলে নির্ভর করে মোটরের ধনাত্মক-ঋণাত্মক প্রান্তের সঙ্গে ব্যাটারির ধনাত্মক-ঋণাত্মক প্রান্ত কীভাবে যুক্ত আছে তার ওপর। অর্থাৎ মোটরে ইনপুট ভোল্টেজের পোলারিটি পাল্টে দিলে মোটরের ঘোরার দিকও বদলে যাবে। এ কাজটাই আমরা করব H-bridge ব্যবহার করে।

একটা H-bridge-এর মধ্যে চারটি সুইচ থাকে এবং মাঝখানে থাকে একটি মোটর। পুরো জিনিসটি দেখতে তাই ইংরেজি H অক্ষরের মতো মনে হয়।

একপাশের সুইচ ক্লোজ করে রাখো এবং বাকি দুটি সুইচ ওপেন করে রাখো তখন তড়িৎ প্রবাহ এক দিকে হয়। অন্য জোড়া সুইচ ক্লোজ করলে তড়িৎ প্রবাহ ঘড়ির কাঁটার বিপরীত দিকে হয় এবং মোটরের ঘূর্ণনও সেই দিকে হয়। এভাবে আমরা H-bridge দিয়ে মোটরের ঘূর্ণনের দিক নিয়ন্ত্রণ করতে পারি।

### L298N

IN1, IN2, IN3 ও IN4। এই চারটি আসলে ইনপুট। এ ক্ষেত্রে যুক্তি খুব সহজ।

ইনপুট ১ LOW, ইনপুট ২ LOW — মোটরটি ঘুরবেই না। যদি প্রথম ইনপুট সচল ও দ্বিতীয় ইনপুট আমরা বন্ধ রাখি তাহলে সামনের দিকে ঘুরবে। আবার প্রথম ইনপুট বন্ধ রেখে দ্বিতীয় ইনপুট সচল রাখলে মোটর পেছনের দিকে ঘুরবে। এই লজিকেই আমরা দুটি মোটরকে কোন দিকে ঘুরবে তা নিয়ন্ত্রণ করতে পারব।

আবার চিন্তা করো মোটরের গতি পরিবর্তনের কথা। মোটরের গতি পরিবর্তনের জন্য আমাদের 4টি ইনপুট পিনের বামে ও ডানে মোট দুটি এনাবল পিন আছে (ENA ও ENB)।

উপকরণ: L298N মোটর ড্রাইভার, আরডুইনো, জাম্পার তার, গিয়ার ডিসি মোটর, 12V অ্যাডাপ্টার, স্ক্রু ড্রাইভার।

মোটর ড্রাইভারের IN1 আরডুইনোর ডিজিটাল 8। IN2 ডিজিটাল 7। IN3 ডিজিটাল 5। IN4 ডিজিটাল 4। ENA ডিজিটাল 9। ENB ডিজিটাল 3। OUT1 ও OUT2 প্রথম মোটরের দুই তার। OUT3 ও OUT4 দ্বিতীয় মোটরের দুই তার। VS 12V অ্যাডাপ্টারের ধনাত্মক প্রান্ত। GND 12V অ্যাডাপ্টারের ঋণাত্মক প্রান্ত। আরডুইনোর Vin 12V অ্যাডাপ্টারের ধনাত্মক প্রান্ত। আরডুইনোর GND অ্যাডাপ্টারের ঋণাত্মক প্রান্ত।

খেয়াল রাখতে হবে 5V জাম্পার খুলে নিলেই একমাত্র মোটরের গতি আমরা নিয়ন্ত্রণ করতে পারব, নইলে শুধু পুরো গতিতে চলবে, গতি কমানো বা বাড়ানোর কাজ করা যাবে না।

কোড বড় দেখে আগেই ভয় পেয়ো না। প্রথমেই আমরা কয়েকটি ভ্যারিয়েবলের মধ্যে জানিয়ে দিয়েছি মোটর A-এর জন্য ENA, IN1, IN2 পিন আমরা কোন ডিজিটাল পিনগুলোতে যুক্ত করেছি। একইভাবে মোটর B-এর জন্য ENB, IN3, IN4 পিন আমরা কোন ডিজিটাল পিনে যুক্ত করেছি।

directionControl ফাংশনে মোটরকে সর্বোচ্চ স্পিডে (analogWrite 255) সামনে ঘোরায়, তারপর দিক বদলায়, তারপর বন্ধ করে। speedControl ফাংশনে 0 থেকে 255 পর্যন্ত গতি বাড়ায়, আবার 255 থেকে 0 পর্যন্ত কমায়।
