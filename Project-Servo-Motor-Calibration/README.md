# Project 14 — Servo Motor Calibration

## Purpose

Calibrate a servo so that its real physical positions correspond more reliably to commanded angles.

## Main Components

- Arduino Uno
- Servo motor
- Jumper wires
- Computer with Arduino IDE / Serial Monitor

## Calibration Process

The example moves the servo through reference positions and then accepts angle commands through the Serial Monitor.

## Code

The Arduino source code is kept separately in `code/servo_calibration.ino`.

## Book Reference

The included pages contain the calibration explanation, circuit, and serial-control example.
