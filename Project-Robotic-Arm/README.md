# Project 13 — Robotic Arm

## Purpose

Build a basic robotic arm mechanism using servo motors. The book explains how servo angles can be used to move the arm and manipulate an object.

## Main Components

- Arduino Uno
- Servo motors
- Jumper wires
- Cardboard or suitable arm structure
- Mechanical joints / servo horns

## Servo Control

The example uses two servo motors connected to Arduino pins 10 and 9.

## Code

The Arduino source code is kept separately in `code/robotic_arm.ino`.

## Book Reference

The included pages show the robotic-arm concept, two-servo setup, and circuit arrangement.
